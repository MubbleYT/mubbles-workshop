First-time setup

  1. Open the Discord Developer Portal, create an application, and go to Bot. Copy its bot token into the connection settings.
  2. Under Bot → Privileged Gateway Intents, enable Server Members Intent and Message Content Intent.
  3. Under OAuth2 → URL Generator, select bot and applications.commands. Add the permissions listed below, open the invite URL, and choose your server.
  4. In Discord, enable User Settings → Advanced → Developer Mode. Right-click your server, roles and channels to copy their IDs.
  5. Move the bot's role above Member and any members it should moderate. Save settings and start.

Permissions: View Channels, Send Messages, Embed Links, Read Message History, Manage Messages, Manage Roles, Moderate Members, Kick Members, Ban Members, Manage Channels, Add Reactions. For the community toolkit: Manage Server (AutoMod), Create Events, Manage Events, Send Polls, Attach Files, Connect, Speak and Move Members.

This bot runs while this app and your PC are on. Closing the browser panel is fine; closing the bot window or putting the PC to sleep takes the bot offline.
